# Software modeling

> Expressing structure and behavior in a notation others can read and tools can check.

## In practice

Developed methodology and guidance for UBS's service and data modeling using UML and
Rational Method Composer, and coached project teams in applying it. Also works with
SysML, OCL, the C4 model and ArchiMate as notations for expressing structure and behavior
that both people and tools can check.

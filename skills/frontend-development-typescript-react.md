# Frontend development (TypeScript, React)

> Building user-facing web applications using TypeScript and component-based frameworks such as React.

## In practice

Build user interface components and manage application state so the interface reflects
underlying data correctly. Use static typing to catch errors before runtime and structure code
so components remain reusable and testable. Optimize rendering performance and handle browser
compatibility and accessibility concerns as the application grows. Typical tools: TypeScript,
React, Redux.

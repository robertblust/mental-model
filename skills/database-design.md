# Database design

> Structuring how data is organized, related and constrained within a database so it supports an application's needs efficiently and correctly.

## In practice

Model entities, relationships and constraints and turn them into a schema that supports the
application's queries. Make trade-offs between normalization, performance and flexibility based
on how the data will be read and written. Review and adjust the schema as usage patterns or
requirements change.

# Enterprise integration

> Connecting systems that were never built to talk to each other.

## In practice

Built DynaRep's service interfaces at UBS on SOAP, generating COBOL and Java
implementations from a shared model. Later, as IT Architect, built the group-wide
Integration Architecture Tool Chain around a canonical data model that bridged business
domain knowledge and technical interfaces — the kind of problem an ESB or a
service-oriented architecture (SOA) solves, with MuleSoft one common way to implement that
pattern.

# CI/CD

> Automating the build, test and release steps that take a code change from commit to running in an environment.

## In practice

Configure pipelines that build and test code automatically on every change and gate progression
on those results. Automate packaging and deployment so releases happen consistently and can be
repeated or rolled back reliably. Monitor pipeline health and adjust stages as the codebase,
tests or release process change. Typical tools: Jenkins, GitHub Actions, GitLab CI.

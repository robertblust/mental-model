# Information security and compliance

> Running a platform so that it can prove it is secure and lawful.

## In practice

Owned security and compliance governance for LIKE MAGIC's platform, alongside the
production cloud platform and PMS integrations. This included building an ISO 27001
program (in progress), GDPR/DSGVO compliance and zero-trust API boundaries around the
public API.

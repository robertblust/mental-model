# How does Robert measure delivery?

> The DORA KPIs define what is watched in how a change reaches production, and none of them is measured yet, so the model makes no claim about how fast anything ships. The Delivery process says how the work itself is done.

## Rests on

| Type | Entity | Owner | For |
| --- | --- | --- | --- |
| kpi | Deployment Frequency | | how often a change ships |
| kpi | Change Lead Time | | how long a change takes to ship |
| kpi | Change Fail Rate | | how often a deployment fails |
| kpi | Failed Deployment Recovery Time | | how soon a failed deployment is recovered |
| kpi | Deployment Rework Rate | | how much shipping is unplanned rework |
| process | Delivery | | how the work is done |

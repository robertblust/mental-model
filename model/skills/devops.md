# DevOps

> Bringing development and operations work together so software is built, tested, released and run as one continuous flow.

## In practice

Build and maintain the automation, tooling and shared practices that let development and
operations teams collaborate on the same pipeline. Work to shorten the cycle between writing
code and running it reliably in production, often owning both the build process and aspects of
live operation. Use feedback from production, such as incidents or performance data, to improve
the development process itself. Typical tools: Docker, Kubernetes, GitHub Actions.

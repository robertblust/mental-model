# Machine learning

> Building models that learn patterns from data and use them to make predictions or decisions on new data.

## In practice

Prepare and explore data, select and train models and evaluate them against relevant performance metrics. Tune model architecture and hyperparameters and validate results against held-out data to avoid overfitting. Monitor deployed models for drift or degraded performance and retrain as needed.

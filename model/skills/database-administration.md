# Database administration

> Installing, configuring and maintaining database systems so they stay available, performant and recoverable.

## In practice

Configure and tune database instances, manage user access and monitor performance and capacity.
Set up and test backup and recovery procedures so data can be restored after a failure.
Diagnose and resolve performance issues, such as slow queries or contention, as they arise.
Typical tools: PostgreSQL, MySQL, Oracle.

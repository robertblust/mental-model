# Integration architecture

> Designing how disparate systems and applications connect and exchange data across an organization.

## In practice

Map the systems that need to exchange data and design the integration patterns, message formats and middleware that connect them. Decide between approaches such as point-to-point connections, an enterprise service bus or event-based integration based on the scale and coupling required. Design for failure handling, data consistency and monitoring across integration points.

# Software engineering

> Designing, writing, testing and maintaining software that meets defined requirements and can be operated reliably over time.

## In practice

Translate requirements into working code, choosing algorithms, data structures and patterns
that fit the problem. Write automated tests, review code with peers and refactor to keep the
codebase maintainable as it grows. Debug and fix defects across the lifecycle, from initial
development through production support.

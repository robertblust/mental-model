# Frontend development

> Building user-facing web applications out of components, in whatever the browser platform has settled on at the time.

## In practice

Build user interface components and manage application state so the interface reflects
underlying data correctly. Choose a framework for the work in front of you and follow it where
it goes, including into a version or a language that a later one replaces, and structure code
so components remain reusable and testable. Reach for static typing where it catches errors
before runtime. Optimize rendering performance and handle browser compatibility and
accessibility concerns as the application grows. Typical tools: React, Angular, AngularJS,
TypeScript, Ionic, Redux.

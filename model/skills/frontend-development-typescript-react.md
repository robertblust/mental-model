# Frontend development (TypeScript, React)

> Building user-facing web applications out of components, in the typed languages and frameworks the browser platform has settled on.

## In practice

Build user interface components and manage application state so the interface reflects
underlying data correctly. Reach for static typing where it catches errors before runtime, and
structure code so components remain reusable and testable. Optimize rendering performance and
handle browser compatibility and accessibility concerns as the application grows. Typical tools:
React, Angular, TypeScript, Redux.

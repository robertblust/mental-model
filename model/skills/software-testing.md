# Software testing

> Verifying that software behaves as intended and catching defects before they reach production.

## In practice

Design test cases that cover expected behavior, edge cases and failure conditions at unit,
integration or end-to-end levels. Execute those tests manually or through automation and
investigate failures to distinguish real defects from flaky tests. Track coverage and defect
trends to focus testing effort where risk is highest. Typical tools: JUnit, Selenium, Cypress.

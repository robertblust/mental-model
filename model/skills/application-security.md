# Application security

> Identifying and mitigating security vulnerabilities in the design and code of software applications.

## In practice

Review application design and code for vulnerabilities such as injection flaws, broken
authentication or insecure data handling. Use static and dynamic analysis tools and manual
testing to find weaknesses before attackers do. Work with development teams to remediate
findings and to build secure practices into the development process itself. Typical tools:
OWASP ZAP, Burp Suite, static analysis tools.

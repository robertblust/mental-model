# LLM application development

> Building software applications that use a large language model to interpret input and generate output as part of the product's functionality.

## In practice

Design prompts, context and application logic that get reliable, useful output from a language
model. Integrate the model into the surrounding application, handling latency, cost and failure
cases specific to model calls. Evaluate output quality and iterate on prompts, context or model
choice as usage patterns emerge. Typical tools: OpenAI API, Anthropic API, LangChain.

# Cloud architecture

> Designing systems that run on cloud infrastructure, using its services and elasticity rather than fixed, self-managed hardware.

## In practice

Select cloud services and design patterns that meet a system's scalability, resilience and cost
requirements. Design for elasticity, fault tolerance across availability zones or regions and
secure use of managed services. Review cost and usage patterns to right-size the architecture
as workloads change. Typical tools: AWS, Azure, Google Cloud Platform.

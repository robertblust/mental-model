# Google Workspace

> Sends id.blust.ch's mail, the code that verifies an address and the owner's invitation, through Gmail from no-reply@blust.ch, signed in as a user of the owner's Google Workspace, and keeps each mail in that user's Sent folder; it may process the mail in any country it chooses, since that Workspace sets no data region.

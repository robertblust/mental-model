# GitHub

> Signs a reader in to id.blust.ch with their GitHub account, when the reader chooses Sign in with GitHub, and tells id.blust.ch the account's id, its login, its name and one email address of the account, the public one on its profile or else its primary verified one, and, for a sign-in not yet linked to an account there, the account's email addresses with whether GitHub verified each, an answer id.blust.ch's link check asks for with that sign-in's access token, uses only to decide whether to link the account or to take a new account's address as verified, and keeps nowhere; it may process the sign-in in any country it chooses.

## Own purposes

- Keeps in the reader's GitHub account that they authorized id.blust.ch to read their email addresses, as an authorized OAuth app the reader can review and revoke under Settings, Applications, Authorized OAuth Apps, under GitHub's privacy statement, for which GitHub, Inc. or GitHub B.V. is the controller.
- Records, for an account an organization supplies, the sign-in for that organization, which GitHub's privacy statement says then "becomes the Data Controller", with GitHub as its processor.

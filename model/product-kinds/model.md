# Model

> A company described once, published as a site, an MCP server and a chat.

## What it means

A product of this kind is opened by whoever wants to know what the company is and does, a reader on the site, a search engine, an agent over MCP, a visitor asking the chat, and every one of them reads the same model. The Mental Model is this kind. There is no other kind yet; a second arrives with the first product that is not a published model.

# CompanyGraph explains its own Obsidian plugin

> A narrated talk in which CompanyGraph describes its own Obsidian plugin, pane by pane and feature by feature, from the pages its own model holds about it.

## Achievements

### Context

- Gave it on Sep 30, 2026 as a talk on companygraph.io, opening on the plugin's own page in the model it edits and ending on where the plugin stops.

### Ways of working

- Built every claim from the plugin's page in the model or a page that page names, a concept, a decision or a role, and named those pages at the foot of each slide, so a listener checks the talk against the model rather than the speaker.
- Showed the plugin at work in drawn reconstructions rather than recordings, said so in the opening, and took the names in them from the real model; the one rename it shows is said to be a demonstration, with nothing in the model renamed.

### Sharing

- Opened on why an instance opens as a vault with no file changed, and on what Obsidian does not know, the schemas: the plugin runs the checks of the meta-model release it bundles against the core the vault vendored, and refuses a vendored core newer than that.
- Walked the plugin through its three panes and the editor: a failure marked on the line it is written, the references that name an entity and the ones it names, and the schema's writing rules beside the cursor, moving with it.
- Showed the editor offering what the schema declares and only that, a declared name read as a link, a missing declared section drawn where it belongs, a rename that follows every reference, and an id set once and locked.
- Tied each behavior to the decision behind it: a reference resolves by its declared type and never by name alone, a frontmatter field is closed while a section is open, and core is vendored at a release the manifest names.
- Closed on what the plugin deliberately does not claim: it reports compliance with the meta-model and nothing about the writing rules, because a check that pretended to judge prose would be believed and wrong, so the editor tells early, the CI decides and a person approves.
- Published it as a self-contained bilingual deck with a transport bar, narration recorded from the speaker notes in each language and a PDF of each.

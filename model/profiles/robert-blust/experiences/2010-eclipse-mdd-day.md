# Eclipse MDD Day 2010

> Co-organized Eclipse MDD Day, brought it to UBS in Zürich-Altstetten and spoke on models as the enterprise's first-class artifacts.

## Achievements

- Co-organized Eclipse MDD Day on 28 October 2010 and hosted it at UBS in Zürich-Altstetten, with itemis co-supporting — the first of the Eclipse events brought to UBS.
- Presented “User Story: Models as First Class Citizens in the Enterprise”, on a program with Ed Merks (EMF project lead), Sven Efftinge (Xtext project lead), Eike Stepper (CDO project lead), and practitioners from SAP, Robert Bosch, RWE and Nord/LB.

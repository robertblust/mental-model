# From one command to fully integrated

> A narrated talk that walks how far a company's model reaches, level by level, from the first command to a model that the checks, an agent and a website are all drawn from.

## Achievements

### Context

- Gave it on Oct 2, 2026 as a talk on companygraph.io, the day the first pack was released, on five levels that each read the one model and keep no second copy of it.

### Ways of working

- Held every level to what is real that day and named under each slide the pages of the model it rests on.
- Told the release of the first pack as the case that climbs the whole ladder, from the one command that took it to the site, the server and the editor each moving one pin, so the levels are shown working on the company that ships them.

### Sharing

- Set out the five levels: model, one command that writes an instance; gated, the same check on every pull request at the release the manifest names; governed, the repositories around the model in one form with what each takes from another declared; served, a read-only server and a chat that answer at a named commit; published, pages drawn from the same files.
- Showed governance as pages of the model too: a rule says what must happen and binds roles, a risk names its cause, consequence and owner, and a control mitigates the one or enforces the other, carried out by a person or pointing at the hook or workflow that does it.
- Named pins as what holds the levels together, each level taking the one below at a tag or a commit and moving only when someone decides, and told the day an unmoved pin turned every pull request red and one moved line fixed them all.
- Closed on where a listener stands rather than on a pitch: a model with a check is already worth having, each level pays for itself before the next, and a level that does not fit is worth being told.
- Published it as a self-contained bilingual deck with a transport bar, narration recorded from the speaker notes in each language and a PDF of each.

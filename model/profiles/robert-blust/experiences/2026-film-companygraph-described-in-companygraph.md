# CompanyGraph, described in CompanyGraph

> A seven-minute film on CompanyGraph's own software as its model describes it, published under a description that walks the parts the film gets right and names three places where it says more than the model does.

## Achievements

### Ways of working

- Generated the film with Gemini Notebook from CompanyGraph's own model, where the parser, the checker, the site builder, the server and the chat are each a bounded context with the invariants it keeps written under a label, so the film walks the software as the model states it rather than as a script retells it.
- Read the transcript against those invariants label by label before publishing and kept every place where the narration leaves the model, from a type check gateway that does not exist to the chat placed in the wrong context, so each could be named before anyone else names it.
- Answered in the published description the three that would mislead a viewer: that the design strips an AI of its ability to invent, where it narrows what an agent has to guess and marks what it cannot back; that the checker refuses badly written pages, where every report says the writing rules were not checked; and that any of it is permanent, perfect or guaranteed.
- Added a voice to the prompt for the next render, the one the earlier films were made under and a line against the absolute words this render used, because the hype words the earlier voice ruled out did not include them.

### Sharing

- Published it on Oct 13, 2026 as about seven minutes with a description that retells four parts of the software in the model's own words — a name that resolves to nothing stops the read, a check reads only the schemas the instance carries, a page is drawn from the model at a pinned commit, and every answer says which commit it was read at — and posted it on LinkedIn the next day around one rule, no edge points nowhere, held by the parser that reads the page it is written on.

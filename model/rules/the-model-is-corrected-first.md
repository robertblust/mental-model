# The model is corrected first

> Where a made thing — a page, a site, a release, an answer — disagrees with the model, the model is corrected first and the thing is rebuilt from it; nothing made is released while the disagreement stands.

## Why

Everything I publish is drawn from one model, so a thing fixed by hand and left disagreeing with the model is a second source that the next build overwrites or, worse, contradicts. Correcting the model first keeps one place where a fact is true.

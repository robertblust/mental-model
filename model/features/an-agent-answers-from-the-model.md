# An agent answers from the model

> Someone asks their own agent about my work and gets what the model says at one commit, named in the answer, instead of what the agent recalls.

## Description

An agent connects over the Model Context Protocol and asks which types the model declares, what one entity says and what evidence a claim rests on, and every answer names the commit it was read from. It only reads, and it adds nothing of its own. It stops at this model: the server is CompanyGraph's, and what it can do is described there; where it runs and what its own page shows belong to the mcp.blust.ch MCP server.

# The model is carried into a conversation

> Someone loads the whole model into the assistant they already use and asks it there, with no server in between.

## Description

The model is exported as bundles — a skill an agent loads, and a set of sources with a reading guide for a notebook — and each is held to being the model whole. It stops at the handing over. A bundle is given on request and published nowhere, and it is as old as its export, so it answers for the day it was made and not for today.

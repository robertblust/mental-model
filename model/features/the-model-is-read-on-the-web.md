# The model is read on the web

> Anyone reads my work in a browser, in English or Swiss German, without cloning a repository and without asking me.

## Description

The pages are drawn from one pinned commit of the model, so a page shows what the model says and a corrected fact is one commit in one place; the parsed model is published beside them as one file anyone may fetch. It stops at reading: nothing on the web writes to the model. What the site must show and how it is built belong to the blust.ch website, and that site's talks and its ideas page are written by hand and are no part of this.

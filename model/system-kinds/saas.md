# SaaS

> Software another party runs and keeps, which the company's own deployments connect to.

## What it means

SaaS is software that another party deploys, runs and keeps, which the company reaches over that party's own interface. Where it handles personal data, the party it runs with is a data processor, and the system's page names it. It is not a deployment, which the company deploys and runs itself, and not the platform a deployment runs on.

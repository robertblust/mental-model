# Survey

> Find out where the open work stands now, not where it stood when it was last looked at.

## What it takes

The Owner's question, and read access to the repositories, pull requests, branches, worktrees and sessions it touches. Where the seat cannot read one of them, it starts anyway and names what it could not see.

## Activities

1. The Surveyor reads the state the question touches where it is held: the pull request on GitHub, the branch in its worktree, the session in its own words.
2. The Surveyor reads the memory for what was settled before, and checks each settled thing it relies on against its current state.
3. The Surveyor sets out the overview: what is open, in what state, who is working on it, each claim linked to where it was read.

## What it produces

| Deliverable | Description |
| --- | --- |
| Overview | What is open, its state and who is working on it, each claim linked to where it was read; finished when nothing in it was taken from an earlier check |

## What it never does

- Never proposes; a choice it finds open is set out for Propose.

## Gate

- Every claim in the overview was checked in this conversation and links to where it was read.
- What the seat could not see is named.

| --- | --- |
| checked again | Survey |

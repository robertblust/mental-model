# Carry

> Do what the Owner's word covers, tell whoever it touches, and report what happened.

## What it takes

The Owner's word from Propose. Where an action the word covers is refused by the seat's permissions, the seat stops there and hands the Owner what is left.

## Activities

1. The Surveyor checks the state the action touches once more, right before acting on it.
2. The Surveyor carries out what the word covers; a commit it makes is made in the seat whose work it carries.
3. The Surveyor tells the sessions the change touches what changed.
4. The Surveyor reports to the Owner what was done, with the commits and pull requests it made, and any mistake it made on the way.

## What it produces

| Deliverable | Description |
| --- | --- |
| Carried decision | What the Owner's word covered, done; finished when the state it changed has been read back |
| Report | What was done and what went wrong, each linked to where it can be read |

## What it never does

- Never leaves out of the report a mistake made on the way.

## Gate

- What the word covered is done and read back from where it is held.
- The sessions it touches were told.
- The Owner has the report.

## If not met

| Outcome | Leads to |
| --- | --- |
| proposed again | Propose |
| handed to the Owner | |

An action the seat's permissions refuse is handed to the Owner with the commands that would do it.

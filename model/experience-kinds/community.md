# Community

> Work done in public — a talk, a seat, a working group, a published case.

## What it means

A period whose output is addressed to a public rather than to one organization: a conference talk, a board or committee seat, a user group, a case study published under someone else's name, a tool put out in the open. Who paid for the time does not decide the kind; an employer can host a talk or publish an article and the period is still this kind, because the audience is. `organization` names the host where there is one — the conference, the group, the publisher, the employer when it published the work itself — and is absent when nobody hosted it. It excludes work whose audience is the organization it was done for, such as a talk to colleagues or a tool built for a client: that belongs to the role or project it was done in.

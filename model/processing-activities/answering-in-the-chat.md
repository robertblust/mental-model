# Answering in the chat

> Answering the question a visitor sends in the chat, from what the model says.

## Data subjects

- Visitors who open the chat and send a message

## Personal data

- What the visitor writes in a message, and the earlier messages of the same conversation
- The visitor's address, to refuse an address that sends too many messages in an hour

## Processors

| Processor | Receives |
| --- | --- |
| Google Cloud | The messages and the visitor's address, on the way to the answer |
| Anthropic | The message and the earlier messages of the same conversation |

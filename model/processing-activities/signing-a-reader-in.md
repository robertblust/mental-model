# Signing a reader in

> Letting anyone open an account at id.blust.ch and sign in with it to the chat, so that the chat knows which models the reader's roles let them choose.

## Data subjects

- People who open an account at id.blust.ch themselves, at its login or by signing in with Google, Microsoft or GitHub
- People the owner makes an account for and invites

## Personal data

- The reader's name and email address, which their account at id.blust.ch holds
- Where the reader's address is not verified, the code the login mails there, which the reader enters before the account is used; an address Google, Microsoft or GitHub proved needs none
- The mail id.blust.ch sends to the reader's address, the code that verifies it or the owner's invitation, which greets the reader by name and is kept as a sent mail until the owner deletes it
- The roles the owner grants the reader, which name the models they may choose; an account holds none until the owner grants one
- For a reader who signs in with Google, the link to their Google account, its id and email address, which their account at id.blust.ch keeps until the link or the account is removed
- For a reader who signs in with Microsoft, the link to their Microsoft account, its id and the email address it names, which their account at id.blust.ch keeps until the link or the account is removed
- For a reader who signs in with GitHub, the link to their GitHub account, its id, its login and the email address id.blust.ch took from it, which their account at id.blust.ch keeps until the link or the account is removed
- Where the reader set one, their password as ZITADEL keeps it, which their account at id.blust.ch keeps
- Where the reader set them up, the public key of their passkey or security key and the secret their authenticator app shares with id.blust.ch, which their account there keeps until they are removed or the account is
- For a reader who signs in with Microsoft while that account is not yet linked, whether it is a personal account or which domains their organization has verified with Microsoft, an answer id.blust.ch's link check asks Microsoft for with that sign-in's access token, uses only to decide whether to link the account or to take a new account's address as verified, and keeps nowhere
- For a reader who signs in with GitHub while that account is not yet linked, the email addresses of their GitHub account and whether GitHub verified each, an answer id.blust.ch's link check asks GitHub for with that sign-in's access token, uses only to decide whether to link the account or to take a new account's address as verified, and keeps nowhere
- The tokens the sign-in issues, kept in the reader's browser, and the access token each message carries to the chat, which checks it

## Processors

| Processor | Receives |
| --- | --- |
| Google Cloud | The reader's name, email address and roles, the link to their Google, Microsoft or GitHub account where they made one, what their account keeps of a password, passkey, security key or authenticator app they set up and the code that verifies an address until it is entered, held by id.blust.ch in its Zurich region, and the access token each message carries; also what the link check reads of each sign-in with Google, Microsoft or GitHub, in the same region and kept nowhere |
| Google | That the reader signs in to id.blust.ch, only when they choose to sign in with Google |
| Google Workspace | The reader's address, their name as the mail greets them and the mail itself, the code that verifies their address or the owner's invitation, sent through Gmail from no-reply@blust.ch and kept as a sent mail until the owner deletes it |
| Microsoft | That the reader signs in to id.blust.ch, only when they choose to sign in with Microsoft, and, while that account is not yet linked, the access token of that sign-in, with which the link check asks Microsoft about the account and its organization |
| GitHub | That the reader signs in to id.blust.ch, only when they choose to sign in with GitHub, and, while that account is not yet linked, the access token of that sign-in, with which the link check asks GitHub for the account's email addresses |
